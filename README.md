Emberkeep — Keeper of the Last Lantern. Night is eating the grove and your lantern is the last light. Move with WASD or the arrow keys, aim with the mouse, and flare (click or Space) to burst the shades apart. Fallen shades drop embers: gather them to feed your flame and raise your score. Chain defeats into combos, hold the light through all ten waves, and dawn breaks. A complete original game in plain HTML5 and canvas: title screen with a living demo behind it, HUD, wave banners, pause, victory and game-over screens with stats and restart, particles, screen shake, and a fully synthesised WebAudio soundtrack — no audio files, no network requests, everything under game/.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. `main.ts` hands the game in for make.fun: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
